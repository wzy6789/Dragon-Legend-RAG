# Flash 官网首字优化

本轮修复官网接入层，不修改各代检索/生成代码快照、参数、评分器或题库。

- 六个 Flash 2.x 代表在服务 ready 前准备完成；常驻六个运行时，字节一致的资料实现共享后端，不再只有两个缓存槽。
- 首段非空正文立即推送；后续按 50ms 窗口或 32 字阈值合并。SSE 新事件唤醒取代固定 250ms 轮询。
- 每版复用网络线程、SDK 客户端和连接池；请求绑定用户 Key，结束时取消并等待残留网络任务退出，再清空授权。失败或取消后不能携带前一个用户的授权进入下个请求。
- 记录版本初始化、客户端准备、内核首字、模型首字等待；原服务端首段、端到端和浏览器接收时间仍保留。缺失的旧数据不补成零。

## 验证结果

后端检查共覆盖 57 项：完整轮次其余 56 项通过，一项测试请求漏填 HTTP method，修正测试夹具后相关 17 项桥接检查全部通过。覆盖首次小段推送、限时合并、SSE 通知唤醒、六版常驻、同资源共享、每请求授权、取消后换 Key、原文保留、参数身份、评分协议和恢复记录。模型通信使用本地模拟 HTTP 传输，未请求真实生成或裁判服务。

前端 15 项既有检查、类型检查及生产构建通过。

线上启动日志确认六版均已准备，资料后端共四份，远程模型调用为零：

| 版本 | 本次启动准备耗时 |
|---|---:|
| flash-2.0 budget_rag | 5228 ms |
| flash-2.0 evidence_select | 5530 ms |
| flash-2.1 context_repair | 5912 ms |
| flash-2.1 single_view | 8783 ms |
| flash-2.2 scene_memory | 797 ms |
| flash-2.2 facet_binding | 774 ms |

两个 2.2 复用了 single_view 的同字节资源包。整项服务启动约 43.8 秒，发生在接受问答请求前。以上是启动准备耗时，不是作答时延；本轮没有真实模型重测，不能据此承诺网站每问一秒完成。
