# 实验工作台可视化实施记录

目标：在其他频道的纯黑、大正文、并排比较改动上继续完成官网 UI，保留当前会话、模型路由和评分协议。

实施：
- A/B 固定蓝绿两色，以字母、名称同时区分；质量与速度摘要优先，答案、评分、执行过程分区切换。

- 评分按原量尺绘制，未知量尺只显示数值，缺失不填零，口径不一致不计算分差。

- 对比组双方独立同步评分，切换视图不影响后台任务。
- 用模拟实验验收有分数、无分数、失败、进行中、不同协议、桌面/窄屏与重连；不跑付费评测。
