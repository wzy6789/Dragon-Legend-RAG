# 实验结果分析面板

沿用纯黑、双栏、字体和现有评分规则，改进报告页可读性及实验追溯。

- 筛选范围摘要、完成/失败/进行中计数，保留原始 P50/P95 算法与有效样本数。
- 质量与执行耗时散点图：按题库、协议、题型、裁判、评分器指纹、量尺严格分组；只画完整生成且成功评分并有合法计时的单次记录，缺失不填零。不计算跨组均分、排名或因果结论。
- 图例、键盘可操作的点、重叠记录选择；直接定位具体回答及详情。
- 逐次运行列表提供问题/版本搜索和状态，批次导出保持整批原始数据。
- 用模拟数据做图表、筛选、不同口径、空值、失败、键盘、桌面/窄屏及回到原答案的浏览器检查；不调用生成与裁判。

验收：前端 87 项测试及类型检查通过；浏览器 23 项检查通过（口径隔离、重叠记录、原回答定位、不同量尺、图例切换、键盘、搜索、完整导出及凭据脱敏、失败记录、排除计数、日期、P50 与排队口径、窄屏）。浏览器全部 API 为模拟数据，未调用生成/裁判。

审查发现 new49 的成功评分结果缺少题型。服务端新增冻结 rubric.profile 的传递；旧记录在读取时从其冻结输入补齐，不读取现题库、不改存量分数。先复现 KeyError，再通过固定样例与不改数据库的兼容测试；57 项后端离线测试通过。
