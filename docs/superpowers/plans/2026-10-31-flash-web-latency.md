# Flash 官网首字优化

依据最近两次 2.2 记录：排队约 50ms，检索约 340–400ms，证据出现前另有约 8 秒准备开销；答案只有 30 字，32 字缓冲使首段延后到结束。

1. 服务 ready 前预热六个固定 2.x 代表；保留六个轻量运行时，不再因两个缓存槽淘汰而反复初始化。完全相同的资源包共享只读后端，本地模型仍只保留一份。
2. 每版本复用网络线程与 HTTP 客户端；Key 仅在当次请求绑定，完成、失败、取消都清除。取消时等待该请求网络任务结束再复用，不跨用户残留授权。
3. 首段非空文字立即持久化并推送，后续按短时间窗口合并；SSE 由事件通知唤醒，保留数据库恢复和心跳。
4. 单独记录版本初始化、客户端准备、内核首字、模型首字等待；保留现有端到端/首段指标和浏览器观测，不改评分。
5. 验证短答即时输出、凭据切换及取消、预热零远程请求、六个代表配置不变；部署后读取健康状态与预热日志。可以运行合成资料和模拟传输，但不使用测试题、不调用付费模型。
