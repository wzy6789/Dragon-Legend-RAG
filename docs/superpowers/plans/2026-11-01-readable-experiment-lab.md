# 可读性与实验操作改进

本轮是用户“持续优化官网 UI、实验性、字体与可读性”目标的一部分。

验收要求：
- 保留纯黑基调、固定左右 A/B、现有版本路由与评分协议。
- 界面、长答案、数值采用明确字体职责；正文支持黑体/宋体、16/18/20 字号、标准/宽松行距，浏览器持久化。
- 对比配置中 A/B 选择器并列，名称和输出列对应；不在两个孤立的行里寻找版本。
- 空白实验台清楚提示自由探索与标准题库入口；不伪造实验数据。
- 表格、引用、列表、代码可读且局部滚动，流式未完成 Markdown 不丢字。
- 必要数据和渲染测试、构建、真实桌面和窄屏检查以及官网部署验证。
- 没有付费生成或评分；原会话和凭据保留。

上轮 UI 已发布；本轮基于 fc3d095。浏览器验证优先使用工具管理的隔离浏览器，先前暴露调试端口的启动方式已被审批拒绝，不重试该方式。

## 本轮验收

- 已通过现有 Playwright Core 的临时浏览器和管道连接完成实际渲染验收，没有开放远程调试端口。

- 48 项前端测试及类型检查通过；新增 Markdown 表格、流式半成品、列表与链接安全检查。
- 浏览器测试使用独立上下文及模拟实验数据，拦截全部 API 请求，真实生成/裁判调用为 0。
- 验收文件：`D:\RAG实验网站\验收\reading-lab-browser.json`、`reading-lab-desktop.png`、`reading-lab-mobile.png`。
- 保留了实际版本路由、评分标准、历史和凭据。发现并修正刷新时把 B 版本恢复成 A 版本的配置问题。
