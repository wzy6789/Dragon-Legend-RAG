# 电脑端纯黑与阅读排版

按用户要求优先调整电脑端，保留原有工作台、版本选择和问答流程。

- 主画布、侧栏、详情面板与登录页底色为 `#000000`；输入框和卡片使用轻微的中性色差与细边框分层。
- 电脑端回答正文 17px，问题 18px，辅助文字至少 13px；同步放大版本说明、历史记录、详情字段、表格和操作按钮。
- 拉开导航、卡片、表格和段落间距；单篇回答限制行宽，双版本对比在宽屏使用更宽的阅读区域。
- 详情面板在小于 1440px 的窗口中浮层展开，保留主阅读区宽度；对比答案根据实际列宽决定并排或上下排列。
- 针对 1366×768 等较矮的电脑屏幕压缩工具区的上下留白，保留字号和正文滚动空间。手机只做基本适配。

验证：前端 15 项既有测试、类型检查及生产构建通过；浏览器检查 1280、1366、1440、1600、1920 宽度的正文、详情、版本卡片和对比布局，并检查基本手机布局。无横向溢出或脚本异常。全部示例仅保存在隔离的预览浏览器中，不是模型真实作答，也不写入用户会话。
